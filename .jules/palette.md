
## 2025-03-05 - Missing Focus Outlines on Marketing Site Elements
**Learning:** Default browser focus rings are frequently suppressed by CSS resets or custom button stylings, hindering keyboard accessibility. For the `website/` marketing site, using the CSS `:focus-visible` pseudo-class allows providing clear, custom focus outlines (e.g., using `--primary` brand colors) specifically to keyboard users without degrading the visual experience for mouse users.
**Action:** When creating or modifying interactive elements (like `a`, `button`, `.btn-primary`, `.doc-card`), always define corresponding `:focus-visible` states. Ensure to suppress the fallback outline on `:focus:not(:focus-visible)` to prevent double outlines.
## 2025-03-05 - Accessible Focus States for Composite Inputs
**Learning:** When using composite input components (like a search bar or prompt bar containing an input field), the default browser focus ring only highlights the inner input element, leaving the outer container visually disconnected. By using `:focus-within` on the parent container (e.g., `.prompt-bar`) and `outline: none` on the inner input (`.prompt-input:focus-visible`), we can create a more cohesive and brand-aligned focus state for keyboard users without causing double focus rings.
**Action:** Always apply interactive focus styles using the `:focus-within` pseudo-class on the wrapper container of composite inputs, and explicitly set `outline: none` on the inner input element to ensure an accessible, unified focus state.

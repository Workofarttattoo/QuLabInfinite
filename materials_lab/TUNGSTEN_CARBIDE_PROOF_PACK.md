## 1. EXACT COMPOSITION & PROCESS STEPS

### Chemical Composition
- **Formula**: WC (tungsten carbide) + Co (cobalt binder)
- **WC Content**: 85-95 wt% (typically 88-92 wt%)
- **Co Content**: 5-15 wt% (typically 8-12 wt%)
- **Carbon Content**: 5.8-6.2 wt% (free carbon <0.1 wt%)
- **Impurity Limits**: <0.5 wt% total (Cr, V, Ta, Ti, etc.)
- **Grain Size**: 0.5-5 μm (submicron for high-performance grades)

### Scalable Synthesis Process: Powder Metallurgy

#### Step 1: Raw Material Preparation (4 hours)
```
Input Materials:
- Tungsten powder (99.9% purity, <1 μm particle size)
- Carbon black (99.9% purity, <100 nm particle size)
- Cobalt powder (99.9% purity, <5 μm particle size)

Process Parameters:
- Stoichiometry: W + C → WC (1:1 atomic ratio)
- Mixing Method: Ball milling or attritor milling
- Milling Media: WC-Co balls (6 mm diameter)
- Milling Time: 24-72 hours
- Milling Speed: 200-400 rpm
- Process Control Agent: 0.5-1 wt% paraffin wax
```

#### Step 2: Carburization (8 hours)
```
Input Materials:
- W+C powder mixture from Step 1

Process Parameters:
- Temperature: 1400-1600°C (two-stage process)
- Stage 1: 1000°C (carbon dissolution)
- Stage 2: 1500°C (WC formation)
- Atmosphere: H₂/Ar mixture (20/80 vol%)
- Holding Time: 2-4 hours at peak temperature
- Furnace Type: Pusher furnace or rotary kiln
- Reaction: W + C → WC (ΔH = -40 kJ/mol)
```

#### Step 3: Milling and Cobalt Addition (6 hours)
```
Input Materials:
- Carburized WC powder
- Cobalt powder (pre-alloyed or elemental)

Process Parameters:
- Milling Method: Ball milling
- Milling Time: 12-24 hours
- Cobalt Addition: 8-12 wt% depending on application
- Milling Atmosphere: Wet milling in organic solvent
- Particle Size Control: D50 = 1-3 μm
- Homogeneity: ±0.5 wt% Co variation
```

#### Step 4: Consolidation (4 hours)
```
Input Materials:
- WC-Co powder mixture

Process Parameters:
- Method 1: Cold Isostatic Pressing (CIP)
  - Pressure: 200-300 MPa
  - Temperature: Room temperature
  - Die Material: Steel or carbide
  - Green Density: 50-60% theoretical

- Method 2: Spray Drying (for large volumes)
  - Binder Addition: 1-2 wt% paraffin
  - Temperature: 150-200°C inlet/outlet
  - Particle Size: 50-200 μm granules
  - Flow Rate: 10-50 L/hour
```

#### Step 5: Sintering (6 hours)
```
Input Materials:
- Green compacts from Step 4

Process Parameters:
- Temperature: 1350-1450°C (solid-state sintering)
- Atmosphere: Vacuum (<10⁻² mbar) or H₂ (reducing)
- Holding Time: 1-2 hours
- Heating Rate: 5-10°C/minute
- Cooling Rate: 5°C/minute to 800°C, then furnace cool
- Final Density: 99.5%+ theoretical
- Grain Growth Control: Inhibitor additions (VC, Cr₃C₂)
```

#### Step 6: Finishing Operations (2 hours)
```
Input Materials:
- Sintered WC-Co blanks

Process Parameters:
- Grinding: Diamond wheels (D15-D150 mesh)
- EDM: Wire or plunge cutting for complex shapes
- Polishing: Diamond paste (1-10 μm)
- Surface Finish: Ra <0.1 μm
- Dimensional Tolerance: ±0.01 mm
```

**Production Scale**: Lab (kg) → Pilot (tons) → Industrial (100 tons/month)  
**Equipment Cost**: $2M sintering furnace + $1M milling equipment  
**Energy Consumption**: 20 kWh/kg (sintering is most energy-intensive)

## 3. MEASUREMENT & VALIDATION PROTOCOL (TEST PLAN)

### Primary Characterization Suite

#### A. Metallographic Analysis (Microstructure)
```
Instrument: Zeiss Axio Observer optical microscope
Sample Prep:
- Sectioning: Diamond wafering blade
- Mounting: Phenolic resin
- Grinding: SiC papers (320-1200 grit)
- Polishing: Diamond paste (6-1 μm)
- Etching: Murakami's reagent (KOH + K₃Fe(CN)₆)

Analysis:
- Grain size: Linear intercept method
- Cobalt distribution: Image analysis
- Porosity: ASTM E112 standard comparison
- Carbide contiguity: Point counting
Standards: ASTM E112, ISO 4499
```

#### B. X-Ray Diffraction (Phase Analysis)
```
Instrument: Bruker D8 Advance diffractometer
Parameters:
- Radiation: Cu Kα (λ = 1.5418 Å)
- Scan Range: 20-100° 2θ
- Step Size: 0.02°
- Scan Rate: 1°/minute
- Analysis:
  - Phase identification: WC, Co, η-phase detection
  - Lattice parameters: WC (a = 2.906 Å, c = 2.837 Å)
  - Crystallite size: Scherrer equation
  - Residual stresses: Peak shift analysis
Standards: ASTM E915
```

#### C. Scanning Electron Microscopy (Composition)
```
Instrument: FEI Quanta 650 FEG-SEM
Analysis Modes:
- Secondary Electron: Topography
- Backscattered Electron: Composition contrast
- Energy Dispersive X-ray (EDX): Elemental mapping
- Wavelength Dispersive X-ray (WDX): Quantitative analysis

Measurements:
- Cobalt binder distribution
- Grain boundary analysis
- Inclusion identification
- Surface chemistry
Standards: ASTM E1508
```

### Performance Testing Protocols

#### Hardness Testing
```
Method: Vickers Hardness (HV30)
Instrument: Wilson Instruments Tukon 2500
Test Parameters:
- Load: 30 kgf (294 N)
- Dwell Time: 15 seconds
- Indenter: Diamond pyramid (136° angle)
- Measurement: Diagonal lengths via optical microscope
Analysis:
- Hardness calculation: HV = 1.8544×P/d²
- Indentation size effect consideration
- Statistical analysis: 10 indentations per sample
Standards: ASTM E384, ISO 6507
```

#### Transverse Rupture Strength Testing
```
Method: Three-Point Bending
Sample Geometry: 6×8×25 mm bars (as-sintered)
Test Parameters:
- Support Span: 20 mm
- Loading Rate: 0.5 mm/minute
- Temperature: Room temperature
- Environment: Laboratory air
Analysis:
- Maximum load determination
- Fracture stress calculation: σ = 3PL/(2bd²)
- Weibull statistics for reliability
- Fracture surface examination
Standards: ASTM B528, ISO 3327
```

#### Wear Testing
```
Method: Pin-on-Disk Tribometer
Test Parameters:
- Counterface: WC-Co disk or SiC abrasive
- Load: 10-50 N
- Speed: 0.1-0.5 m/s
- Distance: 1000-5000 m
- Environment: Dry or lubricated
Analysis:
- Wear volume: Profilometry
- Wear rate: Volume loss per unit load×distance
- Friction coefficient monitoring
- Wear mechanism identification
Standards: ASTM G99, ISO 20808
```

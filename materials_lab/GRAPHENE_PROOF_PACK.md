## 1. EXACT COMPOSITION & PROCESS STEPS

### Chemical Composition
- **Formula**: C (pure carbon, sp² hybridization)
- **Structure**: Hexagonal lattice, single atomic layer
- **Purity Requirement**: >99.9% carbon content
- **Defect Density**: <0.1% (Stone-Wales defects, vacancies)
- **Layer Count**: Monolayer (0.142 nm thickness)

### Scalable Synthesis Process: Chemical Vapor Deposition (CVD)

#### Step 1: Substrate Preparation (30 minutes)
```
Input Materials:
- Copper foil (25 μm, 99.9% purity)
- Hydrogen gas (99.999% purity)
- Argon gas (99.999% purity)

Process Parameters:
- Temperature: 1000°C
- Atmosphere: H₂/Ar (500/500 sccm)
- Time: 30 minutes
- Purpose: Remove surface oxides, achieve atomically flat surface
```

#### Step 2: CVD Growth (30-60 minutes)
```
Input Materials:
- Methane (CH₄, 99.999% purity)
- Hydrogen gas
- Argon gas

Process Parameters:
- Temperature: 1000°C
- Pressure: Atmospheric (1 atm)
- Gas Flow: CH₄ (35 sccm), H₂ (2 sccm), Ar (1000 sccm)
- Growth Time: 45 minutes
- Carbon Source: Methane pyrolysis
- Catalyst: Copper surface (self-limiting growth)
```

#### Step 3: Transfer Process (2 hours)
```
Input Materials:
- Polymethylmethacrylate (PMMA, 950k MW, 4% in anisole)
- Iron(III) chloride (FeCl₃, 1M aqueous solution)
- Acetone (99.9% purity)

Process Steps:
1. Spin-coat PMMA protective layer
2. Float PMMA/graphene on FeCl₃ solution (etch copper)
3. Transfer to target substrate
4. Dissolve PMMA in acetone
5. Rinse and dry under nitrogen
```

**Yield**: 95% monolayer graphene coverage  
**Production Rate**: 10 cm²/minute (lab scale) → 1 m²/minute (pilot scale)  
**Equipment Cost**: $500K CVD system (vs $50M for semiconductor fab)

## 3. MEASUREMENT & VALIDATION PROTOCOL (TEST PLAN)

### Primary Characterization Suite

#### A. Raman Spectroscopy (Quality Control)
```
Instrument: Renishaw InVia Raman Microscope
Laser: 532 nm, 1 mW power
Integration Time: 10 seconds
Key Peaks:
- G peak: 1580 cm⁻¹ (graphitic structure)
- 2D peak: 2700 cm⁻¹ (single layer signature)
- D peak: 1350 cm⁻¹ (defects, target <5% intensity ratio)
Standards: ASTM E2529
```

#### B. Atomic Force Microscopy (Morphology)
```
Instrument: Bruker Dimension Icon
Mode: Tapping mode in air
Tip: Silicon probe (k = 40 N/m)
Scan Rate: 1 Hz
Resolution: 512×512 pixels
Measurements:
- Thickness: 0.8-1.2 nm (monolayer)
- Roughness: <0.1 nm RMS
- Domain Size: >10 μm
```

#### C. Transmission Electron Microscopy (Structure)
```
Instrument: JEOL ARM200F (200kV, aberration-corrected)
Sample Prep: Transfer to lacey carbon grids
Imaging: Bright field, HRTEM lattice imaging
Analysis:
- Lattice constant: 0.246 nm
- Defect density: <0.01%
- Edge termination: Zigzag/armchair ratio
```

### Performance Testing Protocols

#### Mechanical Testing
```
Method: Suspended membrane tensile testing
Sample Geometry: 1-5 μm wide × 10-50 μm long beams
Loading: AFM tip with calibrated spring constant
Data Acquisition: Force-displacement at 1 kHz
Analysis: Stress-strain curves, Weibull statistics
Standards: ASTM E2546 (nanomechanical testing)
```

#### Electrical Testing
```
Method: Back-gated field effect transistor
Geometry: Hall bar (width/length = 1:5)
Contacts: Cr/Au (5/50 nm) evaporated
Measurement: Keithley 4200 semiconductor analyzer
Parameters:
- Gate voltage: -50 to +50 V
- Source-drain: -1 to +1 V
- Temperature: 77-400K
Analysis: Carrier density, mobility, contact resistance
```

#### Thermal Testing
```
Method: Optothermal Raman technique
Excitation: 514 nm laser, modulated
Detection: Anti-Stokes/Stokes intensity ratio
Calibration: Reference materials (silicon, diamond)
Temperature Range: 300-1000K
Analysis: Heat dissipation modeling
Standards: ASTM E1461 (thermal diffusivity)
```
